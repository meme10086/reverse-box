# Reverse Box：逆时推箱

> 一款把「时间回溯」做成解谜本体的 2D 像素推箱子游戏。

**它不是"可以撤销的推箱子"。** 场上每一个对象——玩家，以及每一只箱子——都拥有**各自独立的时间轨迹**，回溯只作用于你选中的那一个：你回溯，箱子留在原地；箱子回溯，你留在原地。

由此得到普通推箱子做不到的解题公式：

> **现在的你 + 箱子过去的位置 = 一个新的推动条件**

最直观的例子：一格宽的走廊里，你在箱子左边，走廊尽头是墙，你永远绕不到它右边——箱子推到尽头就再也推不动了。唯一出路是让它回到起点，而此时你恰好落在它右侧，可以反方向把它推进墙后那间密室。

## 核心玩法

回溯有三条公平性约束：

1. 只能回到该对象**真实经过过**的位置（不能瞬移到地图另一边）
2. 目标格必须**当前空闲**——被墙、被别的箱子、或被你占着的位置会灰掉不可选
3. 不能穿墙、不能凭空生成或复制箱子

回溯次数**不是容错次数**，而是"你能改变几次对象的时间状态"。高级解法会**故意**把箱子推到看似错误的位置，只为了让它的轨迹经过某个关键格，然后再让它回到那里。所以通关按 **S / A / B / C** 评级——用量 ≤ 设计最优 = S，比的是用最少的次数、按正确的顺序完成。

## 操作

| 平台 | 操作 |
|---|---|
| 键盘 | `WASD` / 方向键 = 走一格；`R` = 开/关回溯面板；`T` 或 `Backspace` = 立即重开本关；`Esc` = 返回地图 |
| 回溯面板内 | `A/D`（或 ←→）= 换对象；`W/S`（或 ↑↓）= 翻历史节点；`Enter` / `空格` = 执行回溯 |
| 手机 | 左下虚拟方向键 + 回溯键，全屏滑动走位，面板上直接点 |

## 关卡

共 **30 关**，按三个大关递进：

| 大关 | 关卡 | 考什么 |
|---|---|---|
| 一 | 1–10 | **回谁** —— 一关必须用满两次回溯，而且不止一个对象可选 |
| 二 | 11–20 | 回溯距离上限 + 传送门借道 —— 走廊一格宽、尽头是墙，不回溯在结构上无解 |
| 三 | 21–30 | 双走廊各一只异色箱子，两只都必须被回溯，还要把箱子对到同色地砖上 |

**设计红线：除第 1 关教学外，每一关"不用时间回溯都不可能通关"。** 第 16–30 关全部用精确求解器逐关验证过。

## 技术栈

- **Godot 4.5**（GDScript，GL Compatibility 渲染）
- **像素美术**：AI 出图 + Python 脚本后处理（按背景色抠底 / 清除水印 / 行列投影切帧 / 统一缩放系数 / 16-bit 像素化），原始出图保留在 `assets/art/raw/`、`raw2/`
- **关卡设计**：把机制规则与关卡数据格式整理成说明书交给外部大模型重设计难度曲线 → 产出的关卡再由本地 Python 精确求解器逐关验证可解性与「不用回溯则无解」
- **平台**：Windows / Android

## 构建

```bash
godot --path . --headless --export-release "Windows Desktop" "build/ReverseBox.exe"
godot --path . --headless --export-release "Android" "build/ReverseBox-release.apk"
```

导出预设见 `export_presets.cfg.example` —— 复制为 `export_presets.cfg`，再填入自己的签名密钥路径与密码。

## 逻辑自检

```bash
godot --headless --path . -s res://tests/solve_test.gd    # 退出码 0 = 全部通过
```

覆盖关卡元数据校验、30 关端到端求解（含玩家 / 箱子回溯操作）、传统推箱子规则负向用例、对象独立回溯、历史限制、即时重开、输入映射等。
